# Hikari Skills Lab

Free AI skills for recruiters, for ChatGPT and Claude. Built by recruiters, tested before they're listed.

Browse, copy and download them at https://hikari-ai.co.uk/skills-lab/

## Install (Claude Code, Codex, Cursor)

```
npx skills add HikariBlackStar/skills-lab --skill <name>
```
